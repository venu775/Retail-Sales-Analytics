# 📊 Retail Sales Performance Analysis Dashboard

## Overview
An end-to-end data analytics project using Excel, SQL, and Power BI to analyze retail sales performance and generate actionable business insights.

## Objectives
- Analyze sales performance
- Identify top-performing products
- Understand customer behavior
- Discover regional sales trends
- Provide business recommendations

## Tools Used
- Microsoft Excel
- SQL
- Power BI
